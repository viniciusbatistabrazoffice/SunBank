# SunBank

O SunBank é uma simulação de banco digital. Ele permite cadastrar clientes, autenticar usuários e registrar operações bancárias fictícias (depósito, saque, transferência etc.), sem movimentar valores reais.

## Tecnologias

- **Java 17** + **Spring Boot** (backend)
- **React** (frontend)
- **PostgreSQL** (banco de dados)

## Como executar

### Backend

Requisitos: JDK 17, Maven e PostgreSQL rodando.

```bash
cd backend
./mvnw spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm start
```
